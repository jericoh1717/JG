# PROMPTS DEL PROYECTO JG

## PROMPT 01 — IDENTIDAD
Desarrollar la identidad visual de JG, una marca de joyería y moda dirigida a jóvenes de 18 a 30 años. La marca debe transmitir modernidad, versatilidad, presencia e innovación. Utilizar una estética urbana y minimalista, con negro (#0B0B0F), gris oscuro (#15151C), blanco (#F5F5F5) y morado (#6C3BFF). Utilizar Space Grotesk para títulos e Inter para textos. Eslogan: Tu estilo. Tu presencia.

## PROMPT 02 — MARCO Y DISEÑO WEB
Crear un sistema visual para el sitio web de JG. La página debe tener un diseño moderno, minimalista, urbano y adaptable a computadoras y móviles. Utilizar encabezado fijo, navegación sencilla, secciones independientes, imágenes de joyería y moda, tarjetas de productos, botones con detalles morados, fondos oscuros, animaciones sutiles y buena legibilidad. Incluir Inicio, Nosotros, Colección y Contacto. Mantener coherencia con la identidad visual de JG.
