### Identidad visual
- Se aplicó la identidad visual de JG.
- Se estableció una paleta de colores oscuros.
- Se incorporó el morado como color de acento.
- Se utilizaron Space Grotesk e Inter.

### Diseño y estructura
- Se creó un encabezado con navegación.
- Se desarrolló la sección Hero.
- Se incorporó la sección Nosotros.
- Se creó la colección de productos.
- Se añadieron los valores de la marca.
- Se desarrollaron las secciones Contacto y Footer.

### Componentes
Header, Hero, Nosotros, Coleccion, Beneficios, Contacto y Footer.

### Páginas y funcionalidades
- Inicio.
- Nosotros.
- Colección.
- Contacto.
- Categorías de productos.
- Sección de gafas y relojes.
- Página de pedido con información del producto.

### Adaptabilidad y contenido
- Se añadieron estilos responsive.
- Se agregaron imágenes con atributos alt.
- Se incorporaron enlaces de navegación y redes sociales.

### Tecnologías
Astro, HTML, CSS y JavaScript.
